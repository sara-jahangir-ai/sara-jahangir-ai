## 🌿 Featured Project

### 🔬 PhytoScan AI

**AI-Powered Medicinal Plant Recognition System**

PhytoScan AI is an AI-based image classification project developed during my **BS Artificial Intelligence coursework at NUML**.

The system uses **EfficientNet-B0 and TensorFlow/Keras** to recognize medicinal plant classes from images and provides an accompanying knowledge base and web-based interface.

### What I Worked On

- Image classification using EfficientNet-B0
- Deep learning model development
- Model training and evaluation
- Computer Vision
- Statistical analysis
- Plant information knowledge base
- Streamlit web application

### Technologies

`Python` `TensorFlow/Keras` `EfficientNet-B0` `Scikit-learn` `Pandas` `NumPy` `Streamlit`
